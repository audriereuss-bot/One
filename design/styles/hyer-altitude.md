# Hyer — altitude and assurance

Inspiration only. Never reuse the name, logo, travel claims, people or prices.

## Mood
Expansive editorial white. Monumental bold black grotesk, pale skies,
natural-light photography and architectural colour fields (midnight,
terracotta). Premium but personal; low information density.

## Essentials
- Ink `#000d10`, white canvas, midnight panel `#151623`, media dark `#0f0f1c`, terracotta `#bc7155`, cloud blue `#d3e3f2`, muted `#8e8e95`, rule `#d5d3d4`.
- **Helvetica Now Display** (fallback **Inter**), bold 700 for headings, sentence case, line-height 1, tracking -0.01/-0.02em. All sizes in vw:
  - monumental statement 187px/0.8 (12.99vw) · invitation 130.8px (9.08vw) · heading-lg 63.3px (4.39vw) · opening promise 60px/0.91 · heading 52px · category 36.6px · item 29.5px · benefit 22.5px · body 19.7px/**1.1** · caption 16.9px.
- Identity is a **720×282 monumental wordmark** — half the viewport.
- 24-col grid, 60px side insets; inset compositions 120px.
- Buttons 48px dark pills, 16.9px bold; 48px circular icon controls. Panels are **square** — only selective 25px lower-right corners.

## Signature devices
- **Atmospheric object stage** — 1440×900 sky fading to white clouds, one isolated oblique object ~900px wide across the middle.
- **Dashed journey graphic** — 1px ink cubic S-curve, 6px dash/7px gap, endpoint ring, small silhouette, on terracotta.
- **Framed icon** — 37px thin-line icon in a 93px dashed frame with a rounded lower-right corner.
- **Cloud invitation** — 703px pale-blue fade with soft cloud ellipses; giant 130.8px text-only action.

## Page flow
Identity + promise + object opening (support line left, two pills right, baseline rule) → right-weighted statement with ruled benefits (2 cols) → three-material band (midnight text / photo / terracotta diagram, 480×806 each) → image + index tiles → dark product-in-hand split → 187px principle + framed-icon benefits → wide gallery with big fractional counter → cloud invitation → 634px near-black footer.

## Writing
"We help you…"; tiny promise ("Beyond Travel."); benefit labels 2–3 words; "In simple terms" bridges. No urgency.

## Don't
Rounded elevated cards · terracotta on every element · saturated stock collages · uniform image radii · second decorative font · shrinking the closing invitation to a button.

## Ebook translation
Cover = huge wordmark + one object on sky. Chapter openers alternate white (bold statement) / midnight / terracotta full-bleed. Benefits as hairline-ruled lists; process pages use the dashed journey line. Ideal for premium service guides, travel/retreat ebooks, consulting playbooks.
