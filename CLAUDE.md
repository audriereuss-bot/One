# Working agreement for this repository

This repo is the owner's design studio: websites, landing pages and ebook /
digital-product layouts built from their own inspiration library.

## Before ANY website, landing page, ebook, workbook or digital-product design task

1. Read `design/README.md` (the method + cross-style principles).
2. Read the style file(s) in `design/styles/` that match the brief. If the owner
   names a style ("make it Vivid", "Slash mood", "like the Firm Foundations
   guide"), that file is the spec — follow its numbers, not your defaults.
3. If no style is named, propose the 1–2 best-fitting styles with a one-line
   reason each, then proceed with the first unless told otherwise.
4. For ebooks / PDFs / Canva work, also follow `design/ebook-adaptation.md`.

## Non-negotiables

- Never copy the source brands' names, logos, artwork, claims, prices,
  testimonials or statistics. The styles are for structure, rhythm and craft.
- Never fabricate testimonials, metrics or credentials — leave clearly marked
  placeholders instead.
- Always render and look at the result (desktop + mobile for web, every page
  for ebooks) and fix differences against the style file's Essentials and
  Don'ts before delivering.
- New inspiration the owner shares gets saved as a new file in
  `design/styles/` using the same template, and added to the index.
